## 10. ACHADOS PRINCIPAIS (V2)

1. **Aparato institucional 1980s**: 23 atos bilaterais na década (p.83), incluindo 3 acordos básicos (C&T, nuclear pacífico, cultural/educacional) + consulados/adidâncias — base para CBERS.
2. **Sequência fundadora espacial**: negociação acordo C&T 1982 (p.103) → Ajuste Complementar 1984 → segunda consultas 1988 → 3 instrumentos CBERS abr/jul/ago 1988 (p.131/141-142) — trajetória de continuidade que contrasta com ausência de trajetória equivalente para bambu (gap 1974-2011).
3. **Visitas presidenciais como mecanismo**: Figueiredo 1984 (primeira chefe de Estado) e Sarney 1988 como marcos que geram acordos setoriais múltiplos — modelo de missão que produz memorandos setoriais (ex.: nuclear 1984, transportes 1988).
4. **CBERS como caso-controle de cooperação profunda**: divisão INPE 30%/CAST 70% (Quadro 2 p.141), gestão JPO/JPC/GPM binacional (p.142), vida útil 2 anos depois divisão igual — mostra como cooperação Brasil–China pode atingir transferência/co-produção quando há projeto estruturante (contraponto para avaliar bambu).
5. **Esfriamento 1990-94 documentado**: diálogo político sólido vs. comércio mediano e C&T afetada por finanças (p.304), sem programa amplo China (p.304) — explica descontinuidade que o artigo deve evitar generalizar.
