# Mapa de Lacunas: Reforma Agrária, Agroecologia e Sistemas Agroflorestais no Brasil

*Artefato derivado do Estado da Arte do eixo (Síntese Curatorial Baseada em Evidências). Cada lacuna indica o que falta no corpus documental, por que importa, que fontes já existem, que evidência seria necessária, como se relaciona com a Agenda de Pesquisa e qual a prioridade de curadoria ou pesquisa.*

## 1. Lacunas do corpus (L1–L7)

### L1 — Certificação participativa sem documento normativo integral analisado

| Campo | Conteúdo |
|---|---|
| **Descrição** | Ecovida e SPG/MAPA permanecem como registros; não há documento normativo integral (Lei 10.831/2003, Decreto 6.323/2007, IN 19/2009, textos da Rede Ecovida) analisado na gaveta |
| **Consequência** | Não é possível afirmar, com base no corpus, como a certificação participativa funciona normativamente nem quais são seus limites |
| **Fontes existentes** | [Ecovida — certificação participativa](ecovida-certificacao-participativa.md) (registro) |
| **Evidência necessária** | Texto integral da legislação e dos documentos institucionais; análise das 8 seções |
| **Relação com a Agenda** | **M5** (análise documental integral da certificação participativa) |
| **Prioridade** | Média — pesquisa |

### L2 — Autores clássicos como registros, não fontes analisadas

| Campo | Conteúdo |
|---|---|
| **Descrição** | Altieri, Gliessman, Götsch, Nair e Kageyama & Almeida existem como registros; suas obras não têm texto integral analisado |
| **Consequência** | O estado da arte pode indicar presença, mas não sintetizar conteúdo desses autores |
| **Fontes existentes** | [Altieri](altieri-agroecologia.md), [Gliessman](gliessman-agroecologia.md), [Götsch](gottsch-agricultura-sintropica.md), [Nair](nair-agroforestry-systems.md), [Kageyama & Almeida](kageyama-almeida-agrofloresta-brasileira.md) (registros) |
| **Evidência necessária** | Textos integrais das obras clássicas (ou de capítulos centrais) para fichamento |
| **Relação com a Agenda** | **A3** (curadoria dos 35 registros) |
| **Prioridade** | Alta — curadoria |

### L3 — Referências do artigo Brienza (24 registros) sem texto integral

| Campo | Conteúdo |
|---|---|
| **Descrição** | Das 460 referências catalogadas na revisão de Brienza Júnior et al. (2011), 24 são citadas no estado da arte como registros; nenhuma tem texto integral analisado |
| **Consequência** | As afirmações sobre SAFs amazônicos dependem da revisão-síntese, não das fontes primárias |
| **Fontes existentes** | [Brienza Júnior et al. (2011)](brienza-junior-et-al-2011-sistemas-agroflorestais-amazonia.md) (revisão integral) |
| **Evidência necessária** | Seleção das 24 referências mais citadas; localização de textos integrais; fichamento |
| **Relação com a Agenda** | **A3** (curadoria dos registros) |
| **Prioridade** | Alta — curadoria |

### L4 — RECA UFRRJ e USP em revisão documental

| Campo | Conteúdo |
|---|---|
| **Descrição** | As fichas do RECA (indicadores edáficos — UFRRJ; pecuária em SAFs — USP) são fontes integrais, mas permanecem em revisão documental, não homologadas |
| **Consequência** | O caso RECA não pode ser usado como evidência plena no estado da arte até a revisão ser concluída |
| **Fontes existentes** | [RECA UFRRJ](reca-ufrrj-indicadores-edaficos.md), [RECA USP](reca-usp-pecuaria-safs.md) (em revisão) |
| **Evidência necessária** | Conclusão da revisão documental das duas fichas |
| **Relação com a Agenda** | **M6** (conformação das fichas RECA) |
| **Prioridade** | Média — curadoria |

### L5 — Polanyi (1944) sem texto integral (obra protegida)

| Campo | Conteúdo |
|---|---|
| **Descrição** | A Grande Transformação é obra comercial protegida; a ficha é registro, sem texto integral |
| **Consequência** | O diálogo com a crítica do mercado autorregulado fica indicativo, não analítico |
| **Fontes existentes** | [Polanyi (1944)](polanyi-1944-grande-transformacao.md) (registro) |
| **Evidência necessária** | Capítulos acessíveis, resenhas acadêmicas ou edições com trechos autorizados |
| **Relação com a Agenda** | **A3** (curadoria) |
| **Prioridade** | Média — curadoria (com restrição de direitos autorais) |

### L6 — Período 1970–1990 ausente

| Campo | Conteúdo |
|---|---|
| **Descrição** | A gaveta não contém fontes sobre ocupações, militância e formação dos assentamentos entre 1970 e 1990 |
| **Consequência** | A narrativa histórica do eixo salta da formação fundiária (Petrone 1966) para a etnografia de assentamentos (Pessoa 1997) sem a fase das ocupações |
| **Fontes existentes** | [Petrone (1966)](petrone-1966-baixada-ribeira.md); [Pessoa (1997)](pessoa-1997-revanche-camponesa.md) |
| **Evidência necessária** | Fontes sobre o período: história oral, arquivos, trabalhos sobre a luta pela terra nos anos 1970-1980 |
| **Relação com a Agenda** | **A4** (fontes 1970-1990); **E4** (história oral das ocupações) |
| **Prioridade** | Alta — pesquisa |

### L7 — Economia quantitativa dos assentamentos

| Campo | Conteúdo |
|---|---|
| **Descrição** | Os resumos baianos (Lopes, Nascimento, Dois Riachões, PDS Mário Lago) são descritivos; não há balanços econômicos consolidados |
| **Consequência** | Não é possível afirmar viabilidade econômica nem comparar renda/segurança entre assentamentos com base no corpus |
| **Fontes existentes** | [Lopes et al. (2018)](lopes-et-al-2018-enriquecimento-500-quintais.md); [Nascimento et al. (2018)](nascimento-et-al-2018-producao-agroecologica-assentamentos.md); [Dois Riachões (2024)](promovendo-soberania-alimentar-dois-riachoes-2024.md); [PDS Mário Lago (2024)](agroecologia-soberania-alimentar-pds-mario-lago-2024.md) |
| **Evidência necessária** | Dados econômicos primários: renda, produção, autoconsumo, comercialização; balanços por assentamento |
| **Relação com a Agenda** | **A2** (desenho comparativo dos quintais); **M1** (economia feminista aplicada) |
| **Prioridade** | Alta — pesquisa |
